# iOS Experience (v0.1.0 – foundation)

An Android launcher and customization app with an iOS-inspired look. No root required.

## Status
This is the **first foundation milestone**, not the full product. See `FEATURE_STATUS.md`.
The source was written without access to an Android SDK, so **it has not been compiled or run by the author**.
The GitHub Actions workflow is the first real build; check its result.

## Get the APK
1. Push this folder to a GitHub repository (branch `main`).
2. Open the **Actions** tab, run **Build APK** (it also runs on every push).
3. Download the `iOSExperience-apks` artifact: `iOSExperience-debug.apk` and `iOSExperience-release.apk`.

The release APK is signed with the debug key for testing only.
See `BUILD_GUIDE.md` for local builds.
